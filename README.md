# server

SarnautCore game server (Go): modular shard (world/combat/quests/chat), auth service, gateway; QUIC + protobuf.

## About SarnautCore

This repository is part of SarnautCore, a fan-driven, non-commercial, open-source recreation kit for Allods Online.

The project charter and the architecture decision records live in [SarnautCore/docs](https://github.com/SarnautCore/docs). Read those before opening a pull request here.

## Clean-room posture

SarnautCore is built clean-room. This project never distributes game assets or data owned by MY.GAMES. Anything you run through the kit comes from your own copy of the game, on your own machine.
